⚙ Diagnostics & suggestions

📘
Formatting guide — Chemistry Notes Studio
Everything is text-first. No WYSIWYG lock-in; your .md/.json is portable forever.

★ Headings & structure

★ Coordination Compounds → large topic heading (also # Title)
► Introduction → subtopic (also ## Subtitle)
◆ Definition: → bullet, • nested with 2+ spaces indent
[toc] inserts table of contents, [pagebreak] forces new page.

◆ Boxes & examples

::: keypoint याद रखें ... ::: → colored key-point box
::: example Magnetic moment ... ::: → worked example
::: remember, ::: examtip, ::: formula also supported.

▦ Tables

Use Markdown pipes:
| Property | Octahedral |
| --- | --- |
| CN | 6 | — header repeats on each page automatically.

ƒ Math & chemistry

[eq] \mu_s = \sqrt{n(n+2)} [/eq] → centered equation
Inline $ \frac{a}{b} $ or $\ce{[Fe(CN)6]^{3-}}$ also works
Chemistry auto-formats: H2O → H₂O, SO4^2- → SO₄²⁻, -> → →, <=> → ⇌
Protect verbatim with backticks: `H2O` stays as typed. Highlight with ==yellow==, bold **bold**.

Q Questions

Q1. Which ligand is bidentate?
(A) H2O (B) en (C) NH3 (D) Cl-
[ans] B — answers can be hidden, inline, or on a separate page via the “Answers” selector. Supports [q marks=2] prefix.

🖼 Images (data URLs)

For diagrams, add a JSON image block with embedded data URL (no external URLs):
{"blocks":[{"type":"image","src":"data:image/png;base64,...","text":"Caption","width":"70%"}]}
You can also drag-and-drop an image onto the editor — it will be auto-converted to a data URL and inserted.

⚙ Tips

• Write in Hindi/English mix — Devanagari is fully supported.
• Use -- → – and --- → — automatically.
• Broken glyphs (e.g., Nଶ instead of N₂) are auto-repaired — check Diagnostics for warnings.
• Save/Load stores source + settings as JSON — keep it as your project file.
• Two-column layout is best for cheat sheets; question/worksheet themes add separators.
